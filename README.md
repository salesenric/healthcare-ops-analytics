# Healthcare Operations Analytics

End-to-end analytics project focused on NHS operational performance data, designed to model waiting time and backlog dynamics using Python, BigQuery, dbt, and a lightweight BI layer.

## Goal
Build a production-style analytics workflow that covers:
- raw data ingestion from monthly public releases
- cleaning and normalization
- cloud warehouse loading
- dbt-based transformation layering
- operational marts
- visual analytics for business-facing consumption

## Planned stack
- Python
- BigQuery
- dbt Core
- Tableau Public or Looker Studio
- Git / GitHub
